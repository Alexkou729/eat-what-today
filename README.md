# 今日吃什么 🍳

> 懒人菜谱随机推荐 - 帮你解决"今天吃什么"的选择困难症

![今日吃什么](https://img.shields.io/badge/version-1.0.0-orange)
![License](https://img.shields.io/badge/license-MIT-blue)
![Platform](https://img.shields.io/badge/platform-GitHub%20Pages-brightgreen)

## ✨ 功能特点

### 🏠 随机推荐
- 一键随机生成一道懒人菜谱
- 支持口味偏好筛选（辣/清淡/素食/减脂）
- 智能记住你的口味设置

### 🧊 冰箱模式
- 输入家里有的食材
- 智能匹配可做的菜谱
- 模糊匹配，灵活应对

### ❤️ 收藏功能
- 一键收藏喜欢的菜谱
- 本地存储，永久保存
- 随时查看收藏列表

### 📜 历史记录
- 自动记录浏览历史
- 快速回顾最近查看的菜谱

## 💡 使用技巧

1. **设置口味偏好**：在设置中开启辣/清淡/素食/减脂，随机推荐更精准
2. **冰箱模式**：输入"鸡蛋,番茄"就能找到番茄炒蛋等可用菜谱
3. **快速添加食材**：使用快捷按钮一键添加常用食材
